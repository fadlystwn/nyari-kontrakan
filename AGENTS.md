# AGENTS.md

All agent guidance for this repository lives in `.agents/`:

| Scope | Source of truth |
| --- | --- |
| Whole repo, cross-app contracts | `.agents/AGENTS.md` |
| Backend | `.agents/backend.md` |
| Frontend | `.agents/frontend.md` |

Read `.agents/AGENTS.md` first; it routes you to the area guide. Per-area task workflows (Agent Skills)
live in `.agents/skills/backend/SKILL.md` and `.agents/skills/frontend/SKILL.md`, and all project
documents (backend README, PRD, architecture, security, frontend SEO) live in `.agents/docs/`. This
file, the per-folder `AGENTS.md` files, every `CLAUDE.md`, and `.clinerules/` are discovery pointers
only — never add rules to them.
