# Frontend

The single source of truth for frontend agent guidance is `.agents/frontend.md`; the end-to-end workflow
is `.agents/skills/frontend/SKILL.md`, and the Next.js-managed block it refers to stays in
`frontend/AGENTS.md`. Read them before editing frontend files, and update the guide there when a rule
changes. Do not restate or copy their content into this file.
